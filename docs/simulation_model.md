# Simulation Model

This document outlines the logical/mathematical relationships used to generate synthetic telemetry data for the SDN routing project.

## Telemetry Relationships

To ensure the graph dataset is physically and logically consistent for the GNN to learn from, we model the following cascade of effects for every edge $e$ at timestep $t$:

1. **Offered Traffic ($T_{offered}$)**: 
   The raw data demand generated by the traffic scenario.
   $T_{offered} = Base\_Traffic \times Scenario\_Multiplier(t)$

2. **Utilization ($U$)**:
   The ratio of offered traffic to the link's maximum capacity.
   $U = \frac{T_{offered}}{Capacity}$

3. **Queue Length ($Q$)**:
   As utilization approaches and exceeds safe thresholds (e.g., 80%), packets buffer in queues. Modeled as a non-linear increase:
   $Q = \begin{cases} 0 & \text{if } U \le 0.8 \\ \alpha \cdot (U - 0.8)^2 & \text{if } U > 0.8 \end{cases}$

4. **Delay ($D$)**:
   Total delay combines fixed propagation delay and dynamic queueing delay.
   $D = Delay_{base} + \beta \cdot Q$

5. **Jitter ($J$)**:
   Jitter represents delay variance. It scales with utilization and queue instability, adding bounded random noise.
   $J = \gamma \cdot U \cdot (1 + \text{noise})$

6. **Packet Loss ($L$)**:
   When utilization approaches or exceeds 1.0 (or queue limits are hit), packets are dropped.
   $L = \begin{cases} 0 & \text{if } U \le 0.95 \\ 1 - e^{-\lambda \cdot (U - 0.95)} & \text{if } U > 0.95 \end{cases}$
   *(Capped at maximum 1.0)*

7. **Throughput ($Th$)**:
   The actual successful data transfer rate, bounded by capacity and reduced by packet loss.
   $Th = \min(T_{offered}, Capacity) \times (1 - L)$

## Assumptions
- Traffic demands are aggregated to the edge level rather than simulated packet-by-packet (discrete-time macroscopic simulation).
- Recovery from congestion is instantaneous when demand drops, though a moving average could be added for hysteresis if needed.
- Node features (flow count, incoming/outgoing) are aggregations of edge features.
